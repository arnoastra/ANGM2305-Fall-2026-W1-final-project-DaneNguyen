# Whack A Mole

## Repository
<https://github.com/arnoastra/ANGM2305-Fall-2026-W1-final-project-DaneNguyen>

## Description
Using what I learned and what I'll research I'll make a Whack-A-Mole game. This project will give more experience in many areas and especially implenting sound as that's my main focus here at UTD.  


## Features
- Core game loop
	- A pygame window running a fixed-FPS loop with a grid of holes. Each hole spawns a mole at random. 
- Multiple mole types
	- There'll be different types of moles from normal mole that gives points, penalty mole that deducts points, and a bonus mole that rewards more points. 
- Game states and HUD
	- Start, playing, paused, and game-over screens with on-screen HUD showing the score, timer, and combo.
- Art assets
  - Sprite or drawn images for moles, holes, and the board. As well as sound effects and background music.

## Challenges
- Learning pygame's event loop, suraces, and sprite handling.
- Implementing sprites for the moles, holes, and the board.
- Handling audio playback for sound effects and looping music.

## Outcomes
Ideal Outcome:
- A memorable fun arcade game with multiple mole types, combo scoring, sound, and a saved high score.

Minimal Viable Outcome:
- A working Whack-a-Mole game with moles spawning on a timer, click detection, score tracking, a game-over screen and at least one extra mole type.
